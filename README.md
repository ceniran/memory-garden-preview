# 记忆花田 · 简易原型

这是一个不接真实记忆的独立视觉原型，用合成数据验证两层结构：

- 上方年度日历表示记忆在时间中的分布；
- 下方花田把类型、权重与日期映射为花色、花高和高亮关系。
- 花田以权重映射景深与颜色浓度：权重较高的记忆颜色更深、尺度略大并排在前景，权重较低的记忆颜色更淡、退入远景；日期不参与空间分层。每一层保持相同宽度，形成方形花田而非梯形透视。叶片数量表示一条记忆后来形成的时间节点。
- 花田区域不绘制整块背景，直接使用纯净页面底色；小花生长过半后，才从花脚下渐渐漫出局部、低透明度的模糊绿雾。尚未发芽时完全不绘制花茎，避免圆角线帽形成多余的小点。花茎保持低矮，让远近层次来自密度、透明度和细微尺度差，而不是夸张高度。
- 花冠与叶片采用略大的视觉尺度，花茎进一步压低，既保留密集花田感，也为后续点击单朵记忆预留更清楚的视觉目标与宽于花冠的触控热区。
- 花冠稳定混用圆瓣小花、贝塞尔野花与铃铛花三种代码轮廓。花茎比初版压低约四分之一，花瓣进一步放大，让视觉重心落在可爱的花冠上；铃铛花采用上窄下张、三枚外翻裂瓣与垂落花蕊的轮廓。花型只增加自然多样性；颜色仍是唯一的记忆类型编码：粉色关系、黄色共同经历、蓝色项目、紫色反思。
- 单朵花只保留零至两片叶子，避免密集近景形成鱼骨状轮廓；花田空隙中另放少量不承载数据含义的矮草。草叶从略微错开的根部向不同方向贴地散开，长短不齐并偶有极小侧叶。每撮草会跟随空间上最近的记忆花，像绿色光晕一样在花朵生长过半后才由地面渐渐冒出。
- 花田会按每朵花附近的小范围邻居数量计算局部密度。花越密集，绿色光晕越宽、越浓，草簇出现概率与叶片数量也越高；稀疏区域只保留淡雾与零星矮草。
- 记忆雨不再是循环背景：每一朵记忆花都有一滴落向自身位置的雨。雨滴在约五秒内错落触地；哪滴雨先落下，哪个位置便先发芽、抽茎、开花，再从根部漫出薄雾。整片花田的每一朵花都会完整生长一次，但不会同步排队或统一开花；点击某一天则只重演当天的花。
- 减少动态效果时跳过雨滴与生长过程，直接显示完整花田。

直接用浏览器打开 `index.html` 即可。点击日期会照亮对应的花，点击“重新生长”会重播生长过程。原型使用原生 Canvas，不依赖外部网站或第三方运行时；以后若确定视觉方向，可将合成数组替换为 Dwell 的真实记忆日历接口。

`flower-lab.html` 是独立花型试衣间，以相同尺寸并排展示圆瓣、贝塞尔野花、铃铛花、穗状花与点彩花；所有样品均为本项目重新编写的原生 Canvas 绘制，不会影响主花田。
