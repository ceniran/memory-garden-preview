# 记忆花田 · 简易原型

这是一个不接真实记忆的独立视觉原型，用合成数据验证两层结构：

- 上方年度日历表示记忆在时间中的分布；
- 下方花田把类型、权重与日期映射为花色、花高和高亮关系。
- 花田以日期映射景深：较早的记忆位于淡而密的远景，较新的记忆靠近前景；每一层保持相同宽度，形成方形花田而非梯形透视。叶片数量表示一条记忆后来形成的时间节点。
- 花田区域不绘制整块背景，直接使用纯净页面底色；只在花脚下叠加局部、低透明度的模糊绿雾。花茎保持低矮，让远近层次来自密度、透明度和细微尺度差，而不是夸张高度。
- 记忆雨不再是循环背景：每一滴会按重力落向一条记忆的准确位置，触地泛起浅涟漪，随后依次发芽、抽茎、长叶、开花。初次进入只让最近的几朵重演；点击某一天则只重演当天的花。
- 减少动态效果时跳过雨滴与生长过程，直接显示完整花田。

直接用浏览器打开 `index.html` 即可。点击日期会照亮对应的花，点击“重新生长”会重播生长过程。原型使用原生 Canvas，不依赖外部网站或第三方运行时；以后若确定视觉方向，可将合成数组替换为 Dwell 的真实记忆日历接口。
