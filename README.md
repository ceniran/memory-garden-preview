# 记忆花田 · 简易原型

这是一个不接真实记忆的独立视觉原型，用合成数据验证两层结构：

- 上方年度日历表示记忆在时间中的分布；
- 下方花田把类型、权重与日期映射为花色、花高和高亮关系。
- 花田以权重映射景深与颜色浓度：权重较高的记忆颜色更深、尺度略大并排在前景，权重较低的记忆颜色更淡、退入远景；日期不参与空间分层。每一层保持相同宽度，形成方形花田而非梯形透视。叶片数量表示一条记忆后来形成的时间节点。
- 花田区域不绘制整块背景，直接使用纯净页面底色；小花生长过半后，才从花脚下渐渐漫出局部、低透明度的模糊绿雾。尚未发芽时完全不绘制花茎，避免圆角线帽形成多余的小点。花茎保持低矮，让远近层次来自密度、透明度和细微尺度差，而不是夸张高度。
- 花冠与叶片采用略大的视觉尺度，花茎进一步压低，既保留密集花田感，也为后续点击单朵记忆预留更清楚的视觉目标与宽于花冠的触控热区。
- 记忆雨不再是循环背景：一年中的每一天对应一滴雨，象征日子经过；它不决定花在田里的位置。雨滴按重力落地并泛起浅涟漪，当天有记忆时触发对应花朵生长，没有长期记忆时也会留下短暂湿痕。初次进入只重演最近几天，点击某一天则只重演那一天。
- 减少动态效果时跳过雨滴与生长过程，直接显示完整花田。

直接用浏览器打开 `index.html` 即可。点击日期会照亮对应的花，点击“重新生长”会重播生长过程。原型使用原生 Canvas，不依赖外部网站或第三方运行时；以后若确定视觉方向，可将合成数组替换为 Dwell 的真实记忆日历接口。
